# Clips you generated in Gemini

Put the clips for one remix in `gemini-clips/<slug>/` as `01.mp4, 02.mp4, ...` (order = the pack's clip numbers).
Optional: `music.mp3` (or .wav/.m4a) to cut to. Push, and Claude follows the pack's edit plan, joins them, and
delivers `deliveries/reels/<slug>.mp4` for you to review.
