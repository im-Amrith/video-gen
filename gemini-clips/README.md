# Clips you generated in Gemini

After generating a prompt pack's clips, put them in `gemini-clips/<slug>/` as `01.mp4, 02.mp4, 03.mp4, 04.mp4`
(the slug is in the prompt pack's file name). Optional: `voice.wav` or `voice.m4a` if you recorded the voice-over yourself.
Push, and the session joins them, adds voice, music and captions, and delivers to `deliveries/`.
