# Gemini references: what-if

Put examples of the **what-if** videos you want Gemini to make more of here:
- video clips (`.mp4`, `.mov`, `.webm`; keep each under 25 MB if you upload through the GitHub website)
- screenshots or stills (`.jpg`, `.png`)
- `notes.md`: what you like about them (look, pacing, topics, voice, what to avoid). Claude reads this first.

Claude studies them (see `.claude/skills/gemini-video-prompts`), keeps `STYLE_NOTES.md` up to date,
and writes new prompt packs to `prompts/what-if/`.
